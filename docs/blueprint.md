# **App Name**: VectorVim

## Core Features:

- Canvas Creation: Provide a canvas area where users can draw and manipulate vector graphics.
- Shape Tools: Enable users to add and edit basic shapes (rectangles, circles, lines, paths, and polygons).
- SVG Export: Allow users to export the current canvas as an SVG file.

## Style Guidelines:

- Primary color: White or light gray for a clean canvas appearance.
- Secondary color: Dark gray for UI elements to provide contrast.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean, minimalist layout with the canvas taking center stage.
- Simple, intuitive icons for tools and actions.
